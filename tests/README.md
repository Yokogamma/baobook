# Тести застосунку «Чистий аркуш»

Наскрізні сценарії на Playwright (Chromium). Кожен файл — окремий сценарій, друкує рядки `✓`/`✗` і завершується кодом 1, якщо щось не пройшло. Сторінка відкривається з файлу (`../index.html`), сервер не потрібен.

```sh
cd /path/to/mockups
npm i --no-save playwright@1 && npx playwright install chromium   # один раз; node_modules у .gitignore
node sheet/tests/apparea.mjs
```

Скрипти — ES-модулі, тож `playwright` має лежати в `node_modules` у корені репозиторію (або символічне посилання на іншу теку з ним). Змінна середовища `CHROMIUM` — шлях до бінарника Chromium; без неї береться `/opt/pw-browsers/chromium`, якщо він є (хмарне середовище Claude Code), інакше Chromium самого Playwright.

| Файл | Що перевіряє |
|---|---|
| `appcode.mjs`, `appcode2.mjs`, `appcode3.mjs` | блок коду: вставка, замок, копіювання, перенос, номери рядків, згортання, ручка розміру, меню мови, автовизначення |
| `apptitle.mjs` | назва блока коду (по центру, вузькі картки, пошук) |
| `nl2.mjs` | збереження переносів рядків у тексті |
| `apparea.mjs` | області: протяжка, дочірні блоки, автопідростання, перенос, згортання, кольори, збереження, розгрупування |
| `apptext.mjs` | ручка розміру текстового блока; шапка області, кнопки при наведенні, «⋯» такий самий, як сусідні кнопки |
| `appundo.mjs` | меню «⋯», плашка «Скасувати», Ctrl+Z |
| `appdrop.mjs` | занос блоків в область без «утікання», відступи, сусіди через клітинку |
| `appstore.mjs` | IndexedDB, міграція з localStorage, persist, експорт/імпорт, режим без IndexedDB |
| `appfmt.mjs` | форматування тексту: Ctrl+B/I/U, Ctrl+Shift+S, зняття стилю, збереження, панель при виділенні, чистий текст у списку, переноси рядків, очищення стороннього html |
| `appchip.mjs` | чип «код»: курсор у чипі видно на знімку, → з кінця чипа й клік за ним — набір зовні, Backspace за чипом, подвійний клік (лише чип, не переходить на інший рядок, пробіл після слова як на Windows), Ctrl+E без порожніх рамок і окремо в кожному рядку, Enter і склеювання рядків біля чипа, копіювання без нульових пробілів, ручка розміру не перекриває іконку, старий чип на кілька рядків |
| `appflow.mjs` | стрічка на вузькому екрані: порядок читання, повна ширина, модель не змінюється, вставка між сусідами, «+», перенос за ручку, перенос в область, огляд «як на компʼютері», перемикання за шириною |
| `apptouch.mjs` | дотик: одиночний дотик нічого не створює, утримання створює блок, гортання, кнопка «+», область, підказка (емуляція `hover:none` через CDP) |
| `applabels.mjs` | підписи: дата в списку нотаток (сьогодні — час, цього року — «15 січ.», іншого — з роком), лічильник блоків і «разом із 21 блоком» у відмінках, підказка встановлення на iPhone у підвалі панелі, стилі без правил без селектора, бокове поле аркуша |

Скріншоти й тимчасові файли сценарії пишуть у `<tmpdir>/sheet-tests/`, не в репозиторій. Скидання стану між кроками: `localStorage.clear()` + `indexedDB.deleteDatabase('sheet')` після паузи ≥400 мс (автозбереження має затримку 300 мс). Панель нотаток займає 280px, тож кліки по аркушу — від x≈400.
