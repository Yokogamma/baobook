# Тести застосунку «Чистий аркуш»

Наскрізні сценарії на Playwright (Chromium). Кожен файл — окремий сценарій, друкує рядки `✓`/`✗` і завершується кодом 1, якщо щось не пройшло. Сторінка відкривається з файлу (`../index.html`), сервер не потрібен.

```sh
cd /path/to/mockups
npm i --no-save playwright@1.63.0 && npx playwright install chromium   # один раз; node_modules у .gitignore; та сама версія закріплена в CI
node sheet/tests/apparea.mjs
```

Скрипти — ES-модулі, тож `playwright` має лежати в `node_modules` у корені репозиторію (або символічне посилання на іншу теку з ним). Змінна середовища `CHROMIUM` — шлях до бінарника Chromium; без неї береться `/opt/pw-browsers/chromium`, якщо він є (хмарне середовище Claude Code), інакше Chromium самого Playwright.

| Файл | Що перевіряє |
|---|---|
| `appcode.mjs`, `appcode2.mjs`, `appcode3.mjs` | блок коду: вставка, замок, копіювання, перенос, номери рядків, згортання, ручка розміру, меню мови, автовизначення |
| `apptitle.mjs` | назва блока коду (по центру, вузькі картки, пошук) |
| `nl2.mjs` | збереження переносів рядків у тексті |
| `apparea.mjs` | області: протяжка, дочірні блоки, автопідростання, перенос, згортання, кольори, збереження, розгрупування |
| `apptext.mjs` | ручка розміру текстового блока; шапка області, кнопки при наведенні, «⋯» такий самий, як сусідні кнопки |
| `appundo.mjs` | меню «⋯» області («Видалити область і N блоків»), плашка «Скасувати», Ctrl+Z поза полем; стек: область із блоками — плашка без таймера, ✕ ховає, Ctrl+Z потім повертає; інша нотатка ховає плашку, стек нотатки лишається; два записи повертаються у зворотному порядку; ліміт 20 записів |
| `appnav.mjs` | системний Back на телефоні: панель, меню «⋯» шапки, режим положення, обзор — відкриття кладе запис в історію, Back закриває, закриття з інтерфейсу знімає запис; маршрут «панель → пошук → прокрутка → відкрити → Back повертає панель із запитом і прокруткою → Back ховає»; доступність: усі кнопки з іменами, стрілки й Home/End по панелі положення, Esc виходить; на компʼютері панель записів не робить, меню області — робить |
| `apphistory.mjs` | історія правок: набір і стирання — одним кроком, пауза й перехід курсора — новий крок, Ctrl+Shift+Z, жирний і чипи, кирилична розкладка, окремо в кожному полі, сховище, Ctrl+Z після Esc, стертий блок — з плашкою, назви й код |
| `appdrop.mjs` | занос блоків в область без «утікання», відступи, сусіди через клітинку |
| `appstore.mjs` | IndexedDB, міграція з localStorage, persist, експорт/імпорт, режим без IndexedDB |
| `appfmt.mjs` | форматування тексту: Ctrl+B/I/U, Ctrl+Shift+S, зняття стилю, збереження, панель при виділенні, чистий текст у списку, переноси рядків, очищення стороннього html |
| `appchip.mjs` | чип «код»: курсор у чипі видно на знімку, → з кінця чипа й клік за ним — набір зовні, Backspace за чипом, подвійний клік (лише чип, не переходить на інший рядок, пробіл після слова як на Windows), Ctrl+E без порожніх рамок і окремо в кожному рядку, Enter і склеювання рядків біля чипа, копіювання без нульових пробілів, ручка розміру не перекриває іконку, старий чип на кілька рядків |
| `appflow.mjs` | вузький екран — те саме полотно: позиції за fx і рядом, діти області, правка тексту не рухає блоки (крім виштовхнутих), утримання створює блок там, де палець, «+» під найнижчим, перенос за ручку й в область, огляд «як на компʼютері», масштаб за шириною, модель після перезавантаження |
| `appsel.mjs` | режим положення на дотику: утримання створює блок по обох осях, утримання на тексті або дотик по ручці — рамка і стрілки без клавіатури й системного виділення (текст без курсора для системи невиділюваний, курсор по дотику ставиться в точку дотику), «→» до правого поля, «↑» під блок вище, «←» до лівого поля, «↓» над блок нижче (без сусіда — нічого), «Готово», дотик по тексту ставить курсор, дотик по аркушу знімає режим, перенос за ручку вільний, позиції після перезавантаження |
| `appmenu.mjs` | дії блока і шапки на дотику: «Нова область» першим пунктом «⋯» шапки створює область (кнопки області в шапці немає); шапка області одним рядком 48px — назва зліва в ряду з кнопками, порожня і заповнена; назва області кольором і вагою як «Без назви», порожня без курсора підказки не показує; пересування стрілкою — тихий запис у стеку, «Скасувати: …» у меню «⋯» шапки повертає блок; «⋯» у текстового блока лише у режимі положення або з курсором (зона 44) з «Копіювати блок», «Виділити» (немає, коли блок уже виділено), «Видалити» і поверненням через «Скасувати» на те саме місце; дотик по пункту меню не знімає виділення; «⋯» шапки замість кнопок правопису, сітки, теми й очищення (пункти ≥44px, «Тема» і «Сітка» перемикають, дотик поза меню закриває); кнопки шапки 44×44 і назва на 320px; зона ручки ⋮⋮ ліворуч, а не над текстом; шапка блока коду 44px; на компʼютері «⋯» немає, кнопки 28px |
| `apptouch.mjs` | дотик: одиночний дотик нічого не створює, утримання створює блок, гортання, кнопка «+», область, підказка (емуляція `hover:none` через CDP); утримання з протяжкою по діагоналі малює область (рамка `.marq`, область не ширша за екран, курсор у назві), протяжка лише вниз — звичайний блок; область з меню «⋯» шапки |
| `appkb.mjs` | клавіатура й нижні панелі на дотику: панель форматування видно вже з курсором, «Готово» і «Блок» (новий блок під поточним), без «Копіювати», кнопки 44px, «+» схований, поки курсор у полі, плашка «Скасувати» над панеллю, на 320px молодші кнопки йдуть у «⋯» над панеллю, низьке вікно (клавіатура), довга нотатка: курсор над рядом «⋯», над плашкою й над панеллю після зменшення вікна |
| `appsave.mjs` | статус збереження: на телефоні короткі ● і ✓; відмова сховища → ⚠ у шапці й рядок у панелі з «Повторити» та «Експортувати» (видно на 320px і в низькому вікні); дві незаписані нотатки, перехід між ними без втрати тексту, експорт із памʼяті, beforeunload, повтор запису без перезавантаження, перемикач за `?debug=1`, beforeunload одразу після правки (незавершений запис) і після підтвердження, два записи в польоті з керованим порядком завершення (старіший успіх не знімає новішу помилку), імпорт при відмові йде через той самий облік, причини «сховище переповнене» та назва помилки |
| `applabels.mjs` | підписи: дата в списку нотаток (сьогодні — час, цього року — «15 січ.», іншого — з роком), лічильник блоків і «разом із 21 блоком» у відмінках, підказка встановлення на iPhone у підвалі панелі, стилі без правил без селектора, бокове поле аркуша |

Ті самі сценарії запускає GitHub Actions (`.github/workflows/tests.yml`) на кожен PR і при пуші в `main`; знімки з прогону лежать в артефакті `sheet-tests-screenshots`. Сценарії запускати послідовно: `appdrop` 5a/5b (перенос мишею з перевіркою координат) раз упав, коли паралельно крутилися ще два сценарії, і стабільно проходить наодинці — можлива нестабільність тесту під навантаженням, не доведена вада застосунку. Скріншоти й тимчасові файли сценарії пишуть у `<tmpdir>/sheet-tests/`, не в репозиторій. Скидання стану між кроками: `localStorage.clear()` + `indexedDB.deleteDatabase('sheet')` після паузи ≥400 мс (автозбереження має затримку 300 мс). Панель нотаток займає 280px, тож кліки по аркушу — від x≈400.
